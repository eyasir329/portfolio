| # | Element | Spec |
|---|---|---|
| (1) | Kicker | Small caps, `--muted`, Roman year ornament (`aria-hidden`) |
| (2) | `h1` name | Display serif; LCP element (text, not 3D) |
| (3) | Positioning | Serif italic lede, ≤ 2 lines on D |
| (4) | CTAs | Primary *View work* (filled), secondary *Download CV* (outline). On M they're full width, stacked |
| (5) | Availability badge | Green-ink dot + roles; hidden when "open" is off |
| (6) | 3D hero | Poster first; canvas fades in after idle; `aria-hidden`; not a link |
| (7) | Caption + 3D toggle | Visible caption for everyone; the toggle is `aria-pressed` |
| (8) | Proof strip | 4–6 figures, tabular numerals, each a link (e.g. to `/cp#icpc`) |
| (9) | Section heading with a link | "All work" duplicates nav, placed where the eye ends the row (Z-pattern) |
| (10) | CP summary | One-line ICPC credential first; sparkline is decorative with a text equivalent |
| (11) | Coda | Email as text (copyable) + primary button to `/contact` |

**States:** section hidden when empty (e.g. Writing before the first post); proof figures show a
dash with "syncing" tooltip if missing; 3D unavailable → poster only.
**Heading outline:** h1 name → h2 per section (I–V) → h3 card titles.
**Analytics:** `cta_view_work`, `cta_download_cv` (with location), `proof_click` (figure id).
